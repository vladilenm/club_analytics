# Analytics Club Dashboard

Локальное React-приложение для анализа экспорта участников клуба. CSV разбирается прямо в браузере и не отправляется на сервер.

## Требования

- Node.js 20.19+, 22.13+ или 24+.
- npm 10 или новее.
- Для браузерных тестов — Chromium, устанавливаемый командой `npx playwright install chromium`.

## Установка

```bash
npm install
```

## Локальный запуск

```bash
npm run dev
```

Откройте адрес, который Vite покажет в терминале.

## Импорт CSV

Нажмите «Загрузить CSV» или перетащите файл в зону импорта. Приложение ожидает тот же 17-колоночный формат, что и в экспорте клуба. После успешной проверки все показатели обновятся сразу. Некорректный файл не заменит последние корректные данные.

Реальные CSV-экспорты нельзя коммитить в Git. В репозитории разрешен только синтетический тестовый файл `e2e/fixtures/members.csv`.

## Локальное хранение IndexedDB

Последний успешно импортированный нормализованный снимок хранится в IndexedDB. После перезагрузки он восстанавливается в том же профиле браузера. Хранилище локально для одного профиля и не синхронизируется с другими устройствами. Данные в хранилище браузера не защифрованы самим приложением.

## Показатели за период

В блоке «Показатели за период» нажмите «Загрузить транзакции» и выберите **полную историю за всё время**. Этот импорт независим от CSV участников и работает без него. Нужны столбцы `USER_ID,date,merchant,merchant_info,sum,plan,reflink,promo,comment`. Загрузка следующего полного файла заменяет историю. Ошибка импорта или сохранения оставляет предыдущую историю доступной.

Выберите месяц или даты «С» и «По». Пять карточек считают уникальных участников: на начало и конец периода, новых, ушедших и вернувшихся. События учитываются за все выбранные дни включительно, в UTC. Состояние на начало берётся до событий первого дня, на конец — после событий последнего. Участник может уйти и вернуться несколько раз; в каждой карточке он считается один раз, поэтому складывать карточки в баланс не следует.

**Показатели расчётные:** транзакции не содержат фактических дат окончания каждого доступа. В «Правилах расчёта» можно менять сроки тарифов, способ продления и допуск для технических перерывов. По умолчанию срок начинается от оплаты, а перерывы до 1 часа считаются непрерывным участием, чтобы задержка автоплатежа на несколько секунд не создавала ложное возвращение. Это допущение показано рядом с карточками. Допуск можно обнулить: тогда любой положительный перерыв считается уходом и возвращением.

Сроки по умолчанию: «Старт» и «1 месяц» — 1 календарный месяц, «Практика» и «6 месяцев» — 6, «Система» и «12 месяцев» — 12, «Осенний AI-Сезон» — 3, «Неделя в „Незаменимых“» — 7 дней. Конец календарного месяца ограничивается последним днём целевого месяца. Для нового тарифа нужно указать срок перед расчётом.

Выдачи через `ACCESS_LINK` и операции с нулевой суммой включены как предоставление доступа. Отрицательные суммы и несколько операций одного участника в одну секунду отклоняются как неоднозначные. Ручное снятие/добавление доступа, возвраты денег и отключение автоплатежа из этой истории не восстанавливаются. Неполная история занижает прошлую численность и может ошибочно показывать вернувшихся как новых.

Дата выгрузки берётся из имени `YYYY-MM-DD`; если её нет — используется день импорта. Периоды после этой даты недоступны. День выгрузки может быть неполным, и показатели на его конец предварительные. История и правила сохраняются отдельно в IndexedDB этого браузера. Реальные CSV не попадают в сборку и не отправляются по сети.

## Проверки

Полная проверка типов, стиля, модульных тестов, production-сборки и приватности:

```bash
npm run check
```

Отдельная браузерная приёмка:

```bash
npm run test:e2e
```

## Production-сборка

```bash
npm run build
```

Готовые статические файлы появятся в `dist/`. Перед публикацией запустите `npm run privacy:check` или полную `npm run check`.

## Хостинг

Основной вариант — Sites: опубликуйте содержимое `dist/` как обычный статический Vite-сайт. Если Sites не примет артефакт, используйте Vercel как резервный хост с командой сборки `npm run build` и каталогом публикации `dist`.
